Polices locales à ajouter
=========================

Ce ZIP ne contient pas les fichiers de police.
Déposez vos fichiers .woff2 à ces emplacements exacts :

assets/fonts/bebas-neue/BebasNeue-Regular.woff2
assets/fonts/outfit/Outfit-Variable.woff2

Les appels Google Fonts ont été supprimés des pages HTML.
Le fichier assets/css/theme.css charge maintenant les polices depuis ces chemins locaux.

Si vos fichiers portent un autre nom, renommez-les comme ci-dessus ou adaptez les chemins dans theme.css et dans les liens preload des pages HTML.
